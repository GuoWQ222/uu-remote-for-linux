UU Remote for Linux APT Repository

Ubuntu 24.04 Noble amd64 的签名软件源。

首次添加软件源

从 GitHub Release 下载 uu-remote-for-linux-archive-keyring_1.1.34_all.deb，然后执行：

sudo apt install ./uu-remote-for-linux-archive-keyring_1.1.34_all.deb
sudo apt update

归档签名指纹：652B 3433 62B2 BB96 588B 6085 2422 B98A 64A6 7CCD

X11

sudo apt install uu-remote-for-linux-x11

不会替换 Mutter。

GNOME Wayland

sudo apt install uu-remote-for-linux-wayland

通过普通依赖关系，在同一 APT 事务中安装已验证的 Mutter 修复。安装后必须注销并重新登录 GNOME Wayland。
